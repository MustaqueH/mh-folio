Security & compliance programs

Identity-first access, data protection, and tenant baselines that improve posture without making day-to-day work painful.

Identity · Data · M365

Two programs, one thread

The portfolio cards here point to the same detail page because both bodies of work ran together—conditional access and DLP on one side, Microsoft 365 tenant hardening on the other.

I design guardrails that match how people actually sign in, share files, and collaborate. That means Conditional Access and MFA policies that reduce risky sign-ins without locking out whole regions, DLP rules that stop real data sprawl instead of blocking every attachment, and M365 settings that auditors can trace back to a clear baseline.

Conditional Access & DLP

  • Named locations, trusted devices, and session controls aligned to risk tiers—not one-size “block everything” policies.
  • DLP for Teams, SharePoint, and Exchange tuned to sensitive labels and business workflows.
  • Guest and partner access lifecycle so external sharing stays reviewable.

Microsoft 365: secure by configuration

  • Baseline configuration for Teams, SharePoint, and OneDrive with safe external sharing defaults.
  • Defender and identity integration where it improves signal without duplicating admin work.
  • Documentation and evidence packs that shorten audit conversations.

Technologies & tools

  • Entra ID
  • Conditional Access
  • Microsoft Purview DLP
  • Microsoft 365
  • Defender for Cloud Apps

Impact & outcomes

  • Fewer risky sign-ins and clearer break-glass paths when policies need exceptions.
  • Reduced accidental oversharing and better visibility into guest and link-based access.
  • Stronger audit narrative: baselines, owners, and change history people can follow.
