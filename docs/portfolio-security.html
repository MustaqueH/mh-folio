Security & Compliance

Conditional Access, DLP & Tenant Hardening

Designing guardrails that protect identities and data while keeping the user experience predictable.

Across multiple environments, I’ve implemented Conditional Access, DLP, and Microsoft 365 security baselines to reduce risky sign-ins, lock down sensitive data flows, and keep collaboration safe-by-default. The focus: strong policies, clear exceptions, and minimal friction for legitimate work.

Objectives

  • Reduce risky sign-ins and brute force attempts using Conditional Access and MFA.
  • Protect sensitive information with DLP policies that cover email, SharePoint, and Teams.
  • Standardise security baselines across tenants to simplify operations and audits.

Responsibilities

  • Designed and rolled out Conditional Access policies (location, device compliance, risk-based sign-ins).
  • Implemented DLP rules to control data sharing and exfiltration across Exchange, SharePoint, and OneDrive.
  • Configured security baselines and reviewed Secure Score / Compliance Score trends.
  • Worked with stakeholders to phase in stricter controls without disrupting critical workflows.

Technologies & Tools

  • Entra ID / Azure AD
  • Conditional Access
  • Microsoft 365 Defender
  • DLP Policies
  • Secure Score

Impact & Outcomes

  • Significant drop in risky sign-ins and blocked legacy auth traffic.
  • Reduced accidental data sharing outside the organisation via tuned DLP rules.
  • Improved security & compliance scores with clear evidence for audits.
